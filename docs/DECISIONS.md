# 決定事項

## 2026-10-29 キャンバスの原寸対応

- チャート画像は元の画素数で読み込む。6400 × 1800 px を扱えるよう、キャンバス幅の通常入力上限を8192 pxに広げる。読み込み済み画像・現在値が通常上限を超える場合も、入力確定だけで縮小しない。
- キャンバス設定に「デフォルトに戻す」を追加する。戻し先は選択中のチャート画像の原寸（たたみさん確認済み）、画像なしの場合は1920 × 1080 pxとし、ボタンに寸法を表示する。
- サイズを戻してもFixtureの座標・大きさ・Patchを変更しない。Undoでサイズ変更を取り消せる。
- Mac版とWindows版は同じ変更から作成する。ビルド成功と実機動作確認を区別して報告する。
- 公演名・実画像はリポジトリやPRへ含めない。

## 2026-10-29 LED面・方眼・図形取り込み

- 今回の指示ではLED以外を透明にし、LED面を編集用のグレーで表示する。原画像を保存ファイル内に保持し、チャートメニューから戻せる。グレーと方眼は編集用で、映像出力へ追加しない。
- 色付きの外枠と格子を持つ矩形LED面をローカルで検出する。確信できない画像は加工せず、検出失敗を表示する。任意の写真・曲面・すべての図面の認識は保証しない。
- LED面の左上を基準に既定10pxの方眼と吸着を使う。設定で1〜500pxに変更でき、密すぎる表示倍率では方眼だけ省略する。
- Vectorworks図形はテキストDXF経由で線として取り込む。元の寸法・単位を表示し、指定LED面へ縦横比を保って中央配置する。既存Patchは変更しない。円弧などは折れ線に変換する。
- 直接のVWXコピー＆ペースト、PDF正面図からの寸法・LED配置抽出、指示によるバランス配置は未実装。実際の正面図と対象電飾を受け取ってから寸法・配置規則を確認する。DXFの比率合わせを実寸の校正済みと説明しない。
- 非公開の図面・公演情報・検証スクリーンショットはリポジトリへ追加しない。

## 2026-10-31 配布フォルダの整理

- 配布フォルダの直下には現在のチャート・現在の作業データ・最新版のアプリのみを置く。
- 新しい版を追加するときは、旧版・旧配置案・補助的な確認画像や説明ファイルを、同じフォルダ内の `Old` に移す。削除せず保管する。
- 実行中アプリと現在開いているデータのパスは、整理だけを目的に移動・変更しない。

## 2026-10-31 点灯確認の見やすさ

- 卓なしで確認を開いている間は、キャンバスの選択枠・頂点・Fixture番号・方眼・寸法表示を隠す。閉じると通常の編集表示に戻す。選択とPatchは維持する。
- 認識済みLED面の編集用背景を暗いグレー（#303030）にする。既存データにも適用し、映像出力には含めない。
- 上端配置は線幅まで考慮し、最上段ピクセルの外へ線がはみ出さない位置とする。
